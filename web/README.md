# 楚漢之爭 Web 可玩重製雛形(v1)

## 執行方式
```
cd D:\VS CODE\PROJECT\hanwebgame\web
python -m http.server 8000
```
瀏覽器開啟 http://127.0.0.1:8000

> 直接雙擊 index.html 亦可,但部分瀏覽器對 file:// 載入較嚴格,建議用本地伺服器。

## 內容
- 主選單:新遊戲(選 8 位君主之一)→ 地圖回合制。
- 指令:開發 / 徵兵 / 出兵(鄰城) / 外交停戰 / 結束回合(月份+1,12月進年)。
- AI:其餘勢力(含秦)每回合徵兵並可能攻擊鄰城。
- 存檔/讀檔:localStorage(瀏覽器)。
- 素材:17 張原版畫面(尚未用於地圖,僅備用)、78 張頭像(君主頭像為**暫訂對應**)。

- 君主↔頭像對應為暫訂(face_00.. 依序)。

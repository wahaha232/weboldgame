# BASEDATA.001 分析(Phase 2)

## 檔案
- 大小 11,376 (0x2C70);entropy 5.52;非 MZ;無壓縮跡象。
- 內含大量 Big5 中文(郡縣名、人名)與「AC」開頭檔頭。

## 版面(已驗證)
```
offset       內容
0x0000       檔頭/初始設定 (~0x44;含 "AC"(41 43)、1A 00、多個位元組清單、FF 填充)
0x0044~0x53F 0 填充(長 ~0x4FC)
0x0540       城市表: 39 筆 × 0x30(48)B
0x0C90       人物表: 255 筆 × 0x20(32)B
0x2C70       檔尾
```

### 城市表(39 筆 × 48B @0x540)[VERIFIED 版面]
- 每筆欄位:
  - +0..3: 名稱(Big5,1–2 字,以空白補至 4B)
  - +4..: 多個欄位(含 uint32;如 0x0C 起之 uint32 數值)。小城市(如遼東)
    數值少、大城市(北平/漁陽/三川)有多個非零 uint32(例:0x13880=80000、
    0x9C40=40000、0xBB8=3000、0x1770=6000 等,疑為兵力/糧/錢/開發度…)
  - 不同城市欄位「數目」不同 → 語意需 runtime 驗證
- 39 城中含 27 個有名字;其餘槽位可能供未命名/新增勢力使用。

### 人物表(255 筆 × 32B @0xC90)[VERIFIED 版面]
- 每筆:
  - +0..7: 顯示名(2–4 字 Big5,以 0x20 補位);例 `項羽、劉邦、項梁、嬴胡亥、趙高、李斯、陳勝、吳廣、葛嬰、張耳、陳餘、武臣、邵騷、襄疆、鄧宗、周市、李由、蔡賜、周文、孔鮒、徐公、蒯徹、張敖、韓廣、李良、張黶、章邯、劉伯、劉仲、蕭何、曹參、夏侯嬰、樊噲、田儋、田榮、田橫、魏咎、趙歇、董翳、英布、吳芮、張良、范增、楚心…`
  - +8..0x1F: 24 bytes 屬性(值含 0x00–0xFF;似乎有以 ASCII 可印字元表現的編碼欄位,語意未解)
- 人物順序有脈絡(先群雄後續收錄),與 FACE.GRP 78 張頭像數量無直接對應(255 ≠ 78;頭像索引另存)。

### 檔頭
- `41 43 1A 00`(疑「AC」= 某種簽名/版本)後接多位元組清單 `02 01 04 06 05 07 03 09 08 00 FF…`
  → 疑為開局/勢力相關參數。語意未定。

## 判斷
- 此檔為「靜態初始世界 + 單位資料」檔,不含圖形。
- 城市表內已含預設數值 → 遊戲開始時可能把 BASEDATA 內容複製為「現況」並在存檔(HANSAVE.DAT)中保存一份。見 save_analysis.md。
